Data Masking System

ระบบเซ็นเซอร์ข้อมูลลูกค้าเพื่อความปลอดภัย (PDPA)

Source Code

เครื่องมือเซ็นเซอร์ข้อมูลส่วนบุคคล

กรอกข้อความที่มีข้อมูลส่วนบุคคล ระบบจะทำการใช้ Regular Expression ของ Python (โมดูล re) เพื่อปกปิดข้อมูลสำคัญตามเงื่อนไข

ข้อความจะถูกส่งไปประมวลผลที่ Python server

เงื่อนไขการ Masking

  • บัตรเครดิต: XXXX-XXXX-XXXX-XXXX เหลือแค่ 4 ตัวท้าย (เช่น 1234-5678-9012-3456 → XXXX-XXXX-XXXX-3456)
  • อีเมล: ซ่อนชื่อผู้ใช้ยกเว้นตัวอักษรตัวแรกและตัวสุดท้าย เปิดเผยโดเมน (เช่น somchai.d@company.com → s*******d@company.com)
  • เบอร์โทรศัพท์: XXX-XXX-XXXX เหลือแค่ 4 ตัวท้าย (เช่น 093-245-7894 → XXX-XXX-7894)
  • วันเดือนปีเกิด: ขึ้นต้นด้วย DOB: เซ็นเซอร์ทุกอย่าง ยกเว้น 2 หลักแรกของปีพ.ศ. (เช่น DOB:25/12/2549 → DOB:XX/XX/25XX)
  • ที่อยู่: ขึ้นต้นด้วย Address: เซ็นเซอร์เฉพาะเลขที่บ้าน (เช่น Address: 689 ซอยลาดกระบัง 19... → Address: XXX ซอยลาดกระบัง 19...)
